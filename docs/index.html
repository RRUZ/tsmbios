The library

SMBIOS structures as native Object Pascal types.

SMBIOS describes hardware and firmware information exposed by the system firmware. TSMBIOS reads that data and maps supported structures into Object Pascal records and classes that can be used directly from Delphi and Free Pascal code.

MemoryDeviceInfo.dpr Object Pascal 
procedure ShowMemoryDevices;
var
  SMBios: TSMBios;
  Memory: TMemoryDeviceInformation;
begin
  SMBios := TSMBios.Create;
  try
    if SMBios.HasMemoryDeviceInfo then
      for Memory in SMBios.MemoryDeviceInfo do
      begin
        WriteLn(Format('Size: %d MB',
          [Memory.GetSize]));
        WriteLn(Format('Type: %s',
          [Memory.GetMemoryTypeStr]));
        WriteLn(Format('Speed: %d MT/s',
          [Memory.GetSpeed]));
        WriteLn(Format('Manufacturer: %s',
          [Memory.ManufacturerStr]));
      end;
  finally
    SMBios.Free;
  end;
end;
